Code with DeepSeek in your terminal

An agentic coding CLI — let the AI read your codebase, edit files, run commands and search the web. A Claude Code–style experience, installable in one line.

npm install -g @kavienw/deepseek-cli

Web search

Get started in 30s

# 1) Install
npm install -g @kavienw/deepseek-cli

# 2) Set your API key (platform.deepseek.com/api_keys)
export DEEPSEEK_API_KEY="sk-..."

# 3) Run
deepseek
# or a one-shot question
deepseek "summarize this project"
